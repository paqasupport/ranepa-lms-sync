# RANEPA LMS & BRS Sync (Replace) 🎓

Открытый модуль интеграции с СДО РАНХиГС (`lms.ranepa.ru`) для приложения Расписания КМПО.

Репозиторий создан для максимальной прозрачности: здесь опубликован исходный код серверного парсера, браузерного расширения и скрипта-закладки (Bookmarklet).

## 🔒 Безопасность и режимы работы

### 1. Zero-Trust режим: Закладка (Bookmarklet) и Расширение
- **Не требует ввода логина и пароля.**
- Выполняется непосредственно в браузере пользователя на открытой вкладке `lms.ranepa.ru`.
- Использует текущую сессию браузера (`credentials: 'include'`).
- Забирает только страницы с вашими оценками и дедлайнами заданий, отправляя на сервер Replace готовые данные по одноразовому 6-значному коду привязки.
- Исходный код закладки доступен в [`bookmarklet.js`](./bookmarklet.js).

### 2. Серверная синхронизация (по логину/паролю)
- Авторизуется напрямую в `lms.ranepa.ru/login/index.php`.
- Забирает ведомость оценок и ссылку на календарь iCal с дедлайнами.
- Сессия уничтожается сразу после парсинга.
- Сервер не ведет базу паролей пользователей.
- Исходный код парсера доступен в [`lms_parser.py`](./lms_parser.py).
